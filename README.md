
# PLP Data Analytics Assignment 3
## Duka Sales and Agent Cleanup

**Author:** Anne Waithera Karanja

## Project Overview

This project contains two data analytics engagements.

### Engagement 1: Duka Electronics
Exploration and analysis of sales transactions from January to June 2026. The analysis examines branch performance, product revenue, sales trends and customer purchasing patterns.

### Engagement 2: Mobile Money Agent Network
Data quality auditing, cleaning and analysis of mobile money agent transactions across five Kenyan counties.

## Project Files

- generate_data.py: Generates both datasets.
- duka_sales_exploration.ipynb: Duka sales analysis.
- cleaning_pipeline.py: Reusable agent data cleaning function.
- agent_cleanup.ipynb: Agent data audit and analysis.
- excel/: Branch sales summary workbook.
- outputs/: Cleaned and filtered datasets.
- requirements.txt: Required Python libraries.

## How to Run

Install the dependencies:

```bash
pip install -r requirements.txt
```

Generate the datasets:

```bash
python generate_data.py
```

Open and run the notebooks from top to bottom using Google Colab or Jupyter Notebook.
